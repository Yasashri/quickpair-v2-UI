# QuickPair Frontend

React + Vite dating app frontend for the QuickPair Laravel API.

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   npm run dev
   ```

The frontend proxies `/api` requests to `http://127.0.0.1:8000`.

## Features

- Mobile-first styling with SCSS
- Axios bearer token auth
- Public dating profile browsing
- User profile management and messaging
- Admin login and dashboard
